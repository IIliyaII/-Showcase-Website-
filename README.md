# GitHub Projects Showcase

A simple web application for showcasing GitHub projects in a clean and organized way.

The website displays projects from GitHub and provides a simple interface for viewing and exploring them.

## Features

* Display GitHub projects
* Simple and clean interface
* Project information and details
* Contact page

## Technologies & Modules

This project is built with Python and uses streamlit.


> More details about the modules and dependencies will be added later.

## How to Run

### 1. Clone the repository

```bash
git clone github.com/IIliyaII/-Showcase-Website-
cd Project directory 
```
2. Install dependencies

This project uses uv for dependency management.

```bash
uv sync
```

3. Run the application
```bash
streamlit run Home.py
```
